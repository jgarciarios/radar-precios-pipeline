# Radar de Precios Pipeline
Objetivo: pipeline de datos de producción sobre los datos públicos del SEPA
(precios de supermercados de Argentina). Portfolio para puestos de Data Engineer.
Stack objetivo: Airflow (Docker), dbt, BigQuery (capa gratuita), GitHub Actions,
y al final un servidor MCP que exponga los datos a Claude.
Reglas: avanzar de a una fase, probar cada paso, README claro con diagrama,
nunca commitear credenciales. El dashboard original está en
github.com/jgarciarios/radar-precios-ar.
